# C# Kurs Nov-Dez 2026

Dieses Repository enthält den Quellcode, den wir im Unterricht gemeinsam erarbeitet haben.

Die Solution enthält für jede Aufgabe ein separates Projekt mit Benennung und zugehörigem Foliensatz. Beispiel:

- G04U01_RechteckAufgabe
  - Kapitel: G04
  - Übungsblattaufgabe: 01
  - Titel: Rechteck  

- G04_SpielerAufgabe
  - Kapitel: G04
  - Kein zugehöriges Aufgabenblatt, sondern Beispiel aus den Folien oder Unterricht
  - Titel: Spieler

Die Folien und Aufgabenblätter inklusive Musterlösung finden Sie unter https://github.com/edgeflow-michaelthomas/CSharpMaterial
